# ManteniPro — Sistema de Gestión de Mantenimiento

Aplicación web full stack para gestionar equipos, solicitudes de mantenimiento, técnicos y órdenes de mantenimiento desde una interfaz centralizada.

## Funcionalidades

- **Dashboard:** resumen y seguimiento de la información del sistema.
- **Gestión de equipos:** registro, edición y activación o desactivación de equipos.
- **Solicitudes:** creación y actualización de solicitudes, asignación de técnicos, prioridad y estado.
- **Mantenimientos:** programación de mantenimientos, asignación de técnicos y seguimiento de estados.
- **Gestión de técnicos:** administración de técnicos y sus datos.
- **Base de datos relacional:** almacenamiento de la información mediante PostgreSQL.

## Tecnologías utilizadas

- React
- JavaScript
- Vite
- Node.js
- Express
- PostgreSQL
- Git y GitHub

## Estructura del proyecto

- `frontend/`: interfaz de usuario.
- `backend/`: servidor y lógica de la aplicación.

## Objetivo del proyecto

Proyecto de portafolio desarrollado para practicar la construcción de una aplicación web full stack, la integración entre frontend y backend, las operaciones CRUD y la gestión de datos con PostgreSQL.
